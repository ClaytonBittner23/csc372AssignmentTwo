I did not realize until about halfway through that I was not pushing those commits to github, which I started to do because the storm caused my power to start acting weird.

Semantic HTML: I used header for the header on both pages. I used footer as the footer on both pages. I used figcaption on the second page to add a nice little description. Part of the joke was the description didnt mention the kid eating a ladder. Again, my comedy is subjective. And lastly I used article on the second page when setting up the dual collum style. I figured this pretty well since the right hand of that grid layout would move to be under this main portion.
